reported technology–outcome patterns. The full-network supplements make the
display filtering transparent without interrupting the main argument.

## Network views

- Figure 3 uses each domain's induced subgraph of the full kNN graph, with **all
  within-domain edges**, not a new within-domain nearest-neighbour search. Node
  size is within-domain degree. Baseline: SDG3 has 241 papers/1,063 edges, two
  components (one singleton); SDG16 has 269 papers/1,496 edges, one component.
  The SDG3 singleton is not isolated in the complete graph.
- Figure 4 uses coordinates computed from the complete graph and retains every
  node. The displayed context is at/above the 85th percentile of non-direct-cross
  edge weights (ties included), plus up to the 150 strongest direct SDG3–SDG16
  edges. The 85th-percentile filter includes within-domain and mixed-domain edges.
  Node size and metric cards use the **full graph**, not this displayed subset.
  The eight highest-ranked candidate bridge IDs are labelled.
- S1 draws all retained undirected edges using the same full-graph coordinates.
  It retains mixed-domain papers rather than forcing a two-color classification.
- S2 uses the same full-graph coordinates and saved Louvain membership. It does
  not recompute communities from the filtered display. Colors indicate algorithmic
  membership, not automatically named disciplines or validated substantive themes.

## Drawing and provenance

The full layout uses a deterministic NumPy force algorithm, initialized with saved
PCA positions, for 165 iterations (seed 42). Within-domain layouts use 125
iterations, SDG3 seed 42 and SDG16 seed 43. Layout axes are centered, scaled by the
97th percentile of absolute coordinates, and clipped to the display range. These
display transformations mean that geometric distance is not a calibrated measure
of similarity; edge weights carry the similarity information.

The public renderer calculates counts and modularity from its input graph and
saved partition rather than hard-coding manuscript values. It checks unique IDs,
edge endpoints, duplicate edges, degree consistency, and finite weights/coordinates.
The output manifest records input/script/font hashes, layout seeds, parameters,
and the actual number of displayed edges. The publication PNGs are 450 dpi.
The earlier analytical generators also export vector SVG and PDF versions.

The portable default is DejaVu Sans. The manuscript's earlier Arial export can be
approximated with explicit regular/bold Arial font paths. Font differences and
the corrected white-background transparency compositing can change appearance;
they do not change edges, community assignments, or analysis counts. Verify labels
at final print size before submission. Statistical charts and graph drawings are
generated by Python, not by image-generation models.

## What the discussion can and cannot claim

Use similarity to discuss shared vocabularies, topology to discuss selective
connections, and candidate coding to identify possible technology/outcome pathways.
TAM/UTAUT can explain shared adoption language; dynamic capabilities and TOE can
frame organizational conversion of tools into services; STS and institutional
governance can explain why consent, accountability, capacity, and coordination
condition deployment. These are theory-informed interpretations, not mechanisms
identified by a network algorithm. Avoid repeating frequencies as theoretical
contributions, equating centrality with effectiveness, or interpreting an
undirected semantic edge as an SDG-to-SDG causal arrow.
